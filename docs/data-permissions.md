# 数据分类与检索鉴权

检索结果按「数据分类」授权：运营账号只能检索运营资料和公共资料，读不到财务资料。账号、资料入库和检索使用同一套分类，改一处，其余两处按新规则生效。

平台角色（管理员 / 普通账号）与数据分类相互独立。角色决定能否管理账号和资料，分类决定能读哪些资料。

## 分类与默认规则

固定六类：`public` 公共、`operations` 运营、`finance` 财务、`product` 产品、`sales` 销售、`hr` 人事。

| 对象 | 规则 |
| --- | --- |
| 管理员 | 可读全部分类，包括未分类资料。 |
| 普通账号 | 始终包含 `public`，可再加多个分类。新建时默认只有公共。 |
| 资料 | 可属于多个分类。账号与资料有任一分类相同，或资料含 `public`，即可读取。 |
| 未分类资料 | 普通账号不可读，只有管理员可读。升级前已入库的资料都属于此类，避免旧财报在升级后被误开放。 |
| 其他限制 | 分类检查与已有的个人 / 分组 ACL、撤销状态**同时**生效（两者都通过才可读）。租户隔离不变。 |

## 管理操作

管理账号、调整分类和发布需要管理员账号。成员可在文件中心上传、更新和删除自己的资料；这些操作不会授予发布权限。

**创建账号并授权。** 首页「账号管理」创建账号时勾选分类，已有账号可在列表中「修改权限」。接口为 `POST /admin/users`（`data_domains` 字段）和 `PATCH /admin/users/{username}/domains`。固定管理员 `ragadmin` 的分类不可修改（返回 409）。请求体不能让账号给自己加分类。

**入库时选择分类。** 在文件中心添加文档时选择分类并暂存。管理员进入详情后逐个发布待发布版本。旧管理接口 `POST /documents` 和 `POST /publish` 仍可用。命令行入库用可重复的参数：

```powershell
uv run adaptive-rag ingest --tenant company --document ops-manual --version v1 --file ops.md --data-domain operations
```

分类属于资料本身，不属于某个版本。更新文件不改变分类，命令行的 `--data-domain` 同样不会改动已有分类。未分类资料不会出现在成员检索结果里。例外仅针对管理预览：新建的未分类草稿从未发布且未调整权限时，上传人可以预览自己提交的修订，不因此获得其他版本的读取权。

**外部解析同意与访问权限分开。** 网页提交 PDF 或 Office 时，上传人须确认该原件允许发送给外部 MinerU；即使资料分类为 `public`，也不能跳过本次同意。勾选只授权本次外发，不改变分类、ACL 或发布状态。不能外发的 PDF 可显式调用原有本地接口 `POST /files/pdf` 提取文字层。参见[文件中心](file-center.md)。

**调整已有资料的分类。** 在 `/knowledge` 的资料卡片上修改并保存分类，或调用 `POST /documents/access`，只传 `data_domains` 时不会改动个人 ACL 和撤销状态。分类改动立即生效，包括历史快照。重新入库、发布新版本、回滚都不会恢复旧分类、清除 ACL 或撤销状态。升级前的未分类资料需要管理员逐份分类后，普通账号才能读到。

**图片资料库。** `/images` 上传和编辑图片时同样选择分类，列表、检索、原图、缩略图和检索记录都按分类过滤。

## 检索时的行为

- 检索先筛出账号有权访问的资料，再进行召回、融合、重排和生成。无权的内容不会进入答案、引用、证据或 Trace。
- 账号分类每次请求都从账号库重新读取。管理员改了某账号的分类，该账号已登录的会话在下一次请求就按新分类执行。
- 查询执行期间若权限被撤销，返回答案、完整 Trace 和图片之前会再核验一次，已被撤销的内容不会返回。
- 旧 Trace 和旧证据链接每次读取时按当前权限复核，撤权后读取会被拒绝。普通账号只能读取自己发起的 Trace，管理员读取时仍要通过来源资料的权限检查。

## 接口字段

| 位置 | 字段 |
| --- | --- |
| `GET /access/domains` | 返回分类目录，以及当前账号的 `data_domains`（管理员为 `null`，表示不限制）。 |
| 登录与会话 | `/auth/login`、`/console/session` 返回当前 `data_domains`。 |
| `GET /documents`（管理员） | 返回资料列表、分类、ACL、撤销状态和待发布版本 `staged_jobs`，不含正文。 |
| 图片接口 | 创建与更新支持 `data_domains`，更新时不传则保持原分类。 |

用 Bearer 密钥访问接口时，主体在配置里声明 `data_domains`。非管理员主体没有声明时按只含 `public` 处理，遗漏配置不会变成不限制。命令行的 `query` 等本地命令不带分类限制，属于可信的本机管理入口。

## 数据升级

SQLite 与 PostgreSQL 在启动时幂等地添加分类字段：旧资料的分类为空（未分类），旧普通账号迁移为只含公共，固定管理员不受限制。旧 SQLite 迁到 PostgreSQL 时分类字段一并保留。


升级后的库不能直接交给上一版镜像读写。上一版用位置参数写入，新建账号和资料入库会返回 5xx，而 `/health`、读取和登录仍然正常。回退要先运行 `deploy/downgrade_schema.py` 删除新增的三列，资料分类和账号授权会先导出为 JSON，步骤见 [deploy/README.md](../deploy/README.md)。

## 边界

- 分类是固定的六类，增减分类需要修改 `adaptive_rag/data_access.py` 中的目录。
- 权限覆盖的是本项目 HTTP 与页面入口。直接读取数据目录、数据库或对象存储的人不受这些检查约束，需要用操作系统和云平台的权限另行保护。
