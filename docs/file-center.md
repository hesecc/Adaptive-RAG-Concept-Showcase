# 知识文件管理与回收站

## 管理员与成员怎么用

登录后打开「知识文件管理」（`/knowledge`）。管理员的「全部文件」显示本租户文档与独立图片；「我的上传」按当前账号创建时分配的稳定 ID 筛选。旧文档没有可信的上传人记录，不能被同名账号认领。能检索一份公共资料不代表能在这里改写或删除它。

- **文本或图片：** 文本文档可粘贴正文，也可读取不超过 2 MB 的纯文本、Markdown 或 HTML 文件；预览不会执行 HTML。独立图片仍走图片入口，不提交给 MinerU，也不作为文档修订。
- **PDF 或 Office：** 在同一选择器中选取 `.pdf`、`.doc`、`.docx`、`.xls`、`.xlsx`、`.ppt` 或 `.pptx`，原件须非空且不超过 10 MB（10,000,000 字节）。勾选同意后再提交：服务端会把**完整原件**发送给外部 MinerU，不只是可见文字。更换文件须重新同意。超时后先刷新核对版本再决定是否重试；超时不表示远端任务已取消。
- **暂存与发布：** 解析成功只会暂存。更新时沿用文档 ID、填写新版本号，不改变原有授权；管理员核对内容和分类并发布后，新版本才参与问答。详情中可按版本下载有权读取的原件，用来核对表格、公式和版式。解析用于检索，不是工作簿计算引擎，不会重算公式，也不保证解析结果保留原格式。
- 移入回收站后，即使文件仍占用磁盘空间，检索和旧证据也不应显示它。删除操作不改变访问分类，管理员下架的文件只能由管理员恢复。文件原本未发布，恢复后仍不参与问答。
- 七天从服务器记录的删除时间开始计算（168 小时）。到期不再允许恢复，不依赖定时任务是否及时完成。恢复要携带本次删除的凭证；遇到版本冲突，刷新后核对，不要自动重试覆盖他人变更。

## HTTP 接口

| 操作 | 接口 |
| --- | --- |
| 查询清单 | `GET /files?view=all|mine|trash`（all 限管理员，默认 mine） |
| 查看详情 | `GET /files/{document或image}/{id}` |
| 读取内容 | `GET /files/{document或image}/{id}/content`；可选 `revision`，文档传 `original=true` 可取该版本的归档原件 |
| 暂存文本 | `POST /files/documents` |
| 在线解析并暂存 PDF / Office | `POST /files/parse`；沿用 PDF 上传 JSON，另传小写、不带点的 `extension` 和 `cloud_consent: true` |
| 本地解析 PDF 文字层 | 保留旧接口 `POST /files/pdf`，不调用 MinerU；网页不调用此接口 |
| 上传、修改独立图片 | `POST /files/images`、`PATCH /files/images/{id}` |
| 放入回收站 | `POST /files/{kind}/{id}/trash`。文档携带当前 `expected_generation`，图片携带 `expected_revision` |
| 恢复单项 | `POST /files/{kind}/{id}/restore`，携带 `trash_id`；文档还需 `expected_generation` |

## 运维边界

清理原文、图片、缩略图和派生向量必须与当前引用核对，并与资料写入互斥。定时维护的配置、支持的存储后端及安装条件以 `deploy/retention/` 为准；只升级前端、只启动普通 API 或只删除向量，均不等于启用了物理清理。冷备不在在线文件的保留策略之内。已有服务器必须先验证备份、在副本上演练，并配置维护任务后再宣告上线。切勿让不认识回收站的旧应用直接访问含有回收站记录的数据库。
